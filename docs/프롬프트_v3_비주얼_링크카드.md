4. 먼저 정하고 갈 것 — 팀 합의 한 줄
==================================================

원래 명세에는 이렇게 적혀 있다.

> 지도 자체를 구현하지 않는다. 네이버지도, 카카오맵, Google Maps API를 연결하지 않는다.

이번에 넣는 것은 **API 연동이 아니라 평범한 하이퍼링크**다.

```
지도 API 연동  = SDK 로드, 키 발급, 지도 렌더링, 좌표 처리   → 하지 않는다
지도 딥링크    = <a href="https://map.kakao.com/link/search/...">  → 이번에 넣는다
```

인증키가 필요 없고, 외부 스크립트를 불러오지 않으며, 좌표를 다루지 않는다.
다만 **명세에 적힌 제약을 건드리는 변경**이므로, 구현 전에 팀에서 한 줄로 확인받아라.

> "지도 SDK는 계속 쓰지 않고, 지도 앱으로 넘어가는 링크만 추가합니다. 복사 버튼은 그대로 둡니다."

합의가 안 되면 5번 전체를 건너뛰고 6번(비주얼)만 한다. 복사 버튼(F013)은 어느 경우에도 남긴다.

5. 지도 링크 카드 — 기능 (MUST, 4번 합의 시)
==================================================

## 5-1. 카톡 링크 미리보기와 무엇이 같고 다른가

사용자가 기대하는 모양은 카카오톡 링크 미리보기다. 그건 **서버가 대상 페이지의 OG 태그를 긁어와** 제목·설명·썸네일을 만든 것이다.

우리는 그렇게 할 수 없다. 이유를 정확히 알고 가라.

```
브라우저에서 지도 사이트 HTML을 직접 가져오기 → CORS로 차단
OG 태그를 대신 긁어줄 서버                    → 개발자 2 영역, 이번 범위 밖
외부 썸네일 이미지 불러오기                    → 불필요한 외부 요청, 느려짐
```

따라서 **미리보기를 흉내 내지 말고, 우리가 가진 데이터로 진짜 카드를 만든다.**
우리에게는 이미 시설명·상위 장소·내부 위치·주소가 있다. 카톡 미리보기보다 정확하다.

썸네일 자리에는 **시설 종류별 인라인 SVG 아이콘**을 넣는다. 외부 이미지를 쓰지 않는다.

## 5-2. 카드 구조

```
┌──────────────────────────────────────────┐
│ ┌────┐                                   │
│ │ 🍼 │  수유실                            │   ← 종류 아이콘(SVG) + 시설명
│ └────┘  국립중앙박물관                     │   ← parent_place
│                                          │
│ 어린이박물관 1층                           │   ← location_detail
│ 서울특별시 용산구 서빙고로 137              │   ← address
│ ─────────────────────────────────────    │
│  [ 지도에서 열기 ▸ ]      [ 주소 복사 ]     │
│  카카오맵 · 네이버지도 · 구글지도            │   ← 눌러서 펼치는 선택지
└──────────────────────────────────────────┘
```

- 기본 버튼은 `지도에서 열기` 하나. 지도 앱 선택은 그 아래 작은 링크 3개로 편다.
- 어느 지도를 쓰는지는 사람마다 다르다. 하나를 강요하지 마라.
- 마지막으로 고른 지도를 `localStorage`에 기억해 다음부터 기본으로 올린다.

## 5-3. 링크 만드는 규칙

**서버가 준 `map_search_text`만 쓴다.** 프런트에서 주소를 조합하지 않는다. v1부터 지켜온 규칙이다.

```js
const query = encodeURIComponent(facility.map_search_text);
const MAPS = {
  kakao:  { label: '카카오맵',  url: q => `https://map.kakao.com/link/search/${q}` },
  naver:  { label: '네이버지도', url: q => `https://map.naver.com/p/search/${q}` },
  google: { label: '구글지도',  url: q => `https://www.google.com/maps/search/?api=1&query=${q}` }
};
```

지켜야 할 것.

```
① encodeURIComponent를 반드시 통과시킨다.
② <a target="_blank" rel="noopener noreferrer"> 로 연다.
③ map_search_text가 null·빈 문자열·공백이면 링크와 복사 버튼을 모두 만들지 않는다.
④ location_detail을 검색어에 섞지 않는다. 카드에만 따로 보여준다.
⑤ 링크 텍스트에 주소를 넣지 않는다. 긴 URL을 화면에 노출하지 않는다.
⑥ 복사 버튼은 그대로 둔다. 앱 전환이 막힌 환경에서 유일한 수단이다.
```

## 5-4. 왜 복사 버튼을 남기는가

인앱 브라우저(카톡·인스타 내부 브라우저)에서는 새 창이 막히거나 지도 앱으로 넘어가지 않는 경우가 있다.
링크가 실패해도 사용자는 주소를 손에 쥐고 있어야 한다.

## 5-5. 시설 종류 아이콘

`type` 값에 맞춰 인라인 SVG를 그린다. 없는 종류는 기본 핀 아이콘.

```
restroom  화장실     nursing_room  수유실      diaper_station 기저귀 교환대
parking   주차장     rest_area     쉴 곳        elevator       엘리베이터
```

- 24×24, `stroke` 기반, 브랜드 초록 한 색. 이모지를 쓰지 말고 SVG로 그린다.
- 아이콘만으로 뜻을 전달하지 않는다. 항상 시설명 텍스트와 함께 둔다.

## 5-6. 누른 느낌

- 링크·버튼 `:active`에서 `transform: scale(.98)` + 그림자 축소. 120ms.
- 지도 링크를 누르면 `#sr-live`에 `지도 앱으로 넘어가요.`를 보낸다.
- 복사 성공 시 버튼이 `✓ 복사했어요`로 2초 바뀌는 v2 동작은 그대로 둔다.

## 6-1. 참고 자료를 다루는 방식

첨부 레퍼런스에서 **분위기만** 가져온다. 서비스 성격이 다르므로 구조를 베끼지 않는다.

가져올 것.

```
· 옅은 그라데이션 바탕과 넉넉한 여백
· 큰 모서리 반경, 테두리 대신 부드러운 그림자로 만드는 깊이
· 알약 모양 칩과 알약 모양 입력창
· 작은 반짝임(✦) 하나로 잡는 AI 인상
· Empty / Loading / Response 세 상태를 또렷하게 구분하는 태도
```

가져오지 말 것.

```
· 하단 탭바 — 우리는 화면이 하나다
· 옅은 회색 위 옅은 보라 같은 저대비 조합
· 레퍼런스의 레이아웃·아이콘·일러스트를 그대로 옮기기
  (첨부 이미지 중 하나는 CC BY-NC-ND 표기가 있다. 파생물 제작이 금지된 라이선스이므로
   구성이나 에셋을 옮기지 말고, 색과 여백의 인상만 참고한다.)
· 브랜드 교체 — '온가'의 초록은 유지한다
```

## 6-2. 색

바탕만 그라데이션으로 바꾸고, 글자와 강조색은 지금의 초록 계열을 유지한다.

```css
:root{
  /* 바탕 — 아주 옅게. 위에서 아래로 크림 → 연한 세이지 */
  --bg-top:#FAFBF6;
  --bg-bottom:#EEF3EC;
  --surface:#FFFFFF;
  --surface-soft:#F5F8F2;

  /* 글자 — 대비 우선 */
  --ink:#1F332A;      /* 본문 */
  --ink-soft:#4C5D53;  /* 보조. 흰 배경에서 7:1 이상 */

  /* 브랜드 */
  --green:#2F6652;
  --green-deep:#234E3F;
  --mint:#DCEBE0;

  /* 상태 — 색과 아이콘과 텍스트를 항상 함께 */
  --warn:#8A5A16;  --warn-bg:#FDF4E3;
  --alert:#8A4228; --alert-bg:#FDEDE6;
  --calm:#2C5C37;  --calm-bg:#E9F4E7;
}
body{ background:linear-gradient(180deg,var(--bg-top) 0%,var(--bg-bottom) 100%); background-attachment:fixed; }
```

보라·라벤더를 넣고 싶으면 **바탕 그라데이션의 아주 옅은 끝단에만** 쓴다. 글자나 버튼에 쓰지 않는다.

## 6-3. 깊이와 모양

테두리 1px을 걷어내고 그림자로 층을 만든다.

```css
--r-card:24px;  --r-inner:16px;  --r-pill:999px;
--shadow-1:0 1px 2px rgba(31,51,42,.05), 0 2px 8px rgba(31,51,42,.05);
--shadow-2:0 4px 12px rgba(31,51,42,.07), 0 16px 32px rgba(31,51,42,.06);
```

- 대화 카드: `--shadow-2`, 반경 `--r-card`
- 시설 카드·상세 블록: `--shadow-1`, 반경 `--r-inner`
- 칩·버튼·입력창: `--r-pill`
- 테두리는 구분이 꼭 필요한 곳에만 `1px solid rgba(31,51,42,.08)`

## 6-4. 타이포와 여백

```
h1            26px / 700 / -0.8px
장소명 h3      24px / 700
본문           17px / 1.7
보조           15px / 1.6
버튼·칩        16px / 600
여백 단위      4px 배수. 카드 안쪽 20px, 카드 사이 16px, 묶음 사이 28px
```

한 카드 안에서 글자 크기는 3종을 넘기지 않는다.

## 6-5. 세 가지 상태를 또렷하게

레퍼런스의 `01 Empty / 02 Loading / 03 Response` 구성을 우리 화면에 맞게 만든다.

**01 Empty (첫 화면)**

```
· 바탕 그라데이션 위에 카드 하나만 떠 있는 인상
· 반짝임 ✦ + 인사 두 줄 + 유형 칩 3개
· 추천 질문은 아직 보여주지 않는다 (유형을 모르므로)
· 스크롤 없이 입력창까지 보이는 v2 기준 유지
```

**02 Loading**

```
· 봇 자리에 말풍선 모양 스켈레톤 한 개 + 점 세 개
· 로딩 3단계 문구 유지
· 회색 덩어리를 여러 줄 깔지 않는다. 한 줄이면 충분하다
```

**03 Response**

```
· v2의 3층 구조 유지
· 1층 편안함 배지를 카드 상단 색 띠로 승격 (아이콘+텍스트 유지)
· 2층 조건 3줄은 아이콘 원형 배지 + 라벨 + 근거
· 시설 카드는 5번의 새 구조
· 3층 <details>는 접힌 상태에서도 무엇이 들었는지 보이게
  summary를 "자세히 보기" → "이동·편의 정보, 출처 보기"로
```

## 6-6. 대비 가드레일 — 분위기보다 우선

부드럽게 만들다가 흐려지는 것을 막는다. 아래를 어기면 그 디자인은 채택하지 않는다.

```
본문 대비        4.5:1 이상
18px 이상 큰 글자 3:1 이상
버튼 배경 대 글자 4.5:1 이상
비활성 요소도    3:1 이상
placeholder      4.5:1 이상 (연한 회색 금지)
경계선            배경과 최소 1.5:1, 또는 그림자로 대체
```

`prefers-contrast: more`에서는 그림자를 실선 테두리로 바꾼다.

```css
@media (prefers-contrast: more){
  .answer-card,.facility-card{ border:2px solid var(--ink); box-shadow:none }
}
```

색만으로 뜻을 전달하지 않는 v1 규칙은 그대로다. 편안함 4단계는 색 + 아이콘 + 텍스트를 항상 같이 쓴다.

==================================================
7. Personalization — 지난번을 기억한다
==================================================

`localStorage`에 마지막 선택을 남기고, 다시 왔을 때 첫인사를 바꾼다.

```json
{ "travelerType": "senior", "needs": ["stairs_difficult","need_rest_area"], "mapApp": "kakao", "savedAt": "2026-09-04" }
```

- 처음 방문: `누구랑 가세요?`
- 다시 방문: `지난번처럼 부모님과 가시나요?` + `[ 네, 그대로 ]` `[ 아니요, 바꿀게요 ]`
- `네, 그대로`를 누르면 조건까지 복원하고 바로 질문을 받는다.
- 30일이 지난 기록은 버린다.
- 개인정보나 질문 내용은 저장하지 않는다. 유형·조건·선호 지도만.
- `localStorage` 접근은 `try/catch`로 감싼다. 실패하면 처음 방문처럼 동작한다.
