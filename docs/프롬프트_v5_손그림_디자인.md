2. 레퍼런스에서 가져올 것 / 가져오지 말 것
==================================================

첨부한 Doodle Chat 화면은 **분위기 참고용**이다. 서비스 성격이 다르므로 구조를 베끼지 않는다.

## 가져올 것

```
· 삐뚤삐뚤한 잉크 테두리 — 자로 잰 듯한 선을 버린다
· 형광펜으로 그은 강조 — 로고와 중요한 단어 뒤에
· 마스킹테이프로 붙인 메모지 — 살짝 기울어진 채로
· 손으로 그린 별·하트·화살표·물결 — 여백에 흩어 놓기
· 파스텔 채움 + 진한 잉크 선의 조합
· 손으로 그린 체크박스와 체크 표시
· 동글동글한 손글씨 (단, 6번의 제한을 반드시 지킬 것)
```

## 가져오지 말 것

```
· 3단 레이아웃, 연락처 목록, 오른쪽 사이드바 — 우리는 화면이 하나다
· 브라우저 창을 그린 액자 — 실제 브라우저 안에서 도는 서비스다
· 읽지 않음 뱃지, 통화·영상 아이콘 등 없는 기능의 장식
· 레퍼런스의 캐릭터 일러스트와 아이콘을 그대로 옮기기
```

## 레퍼런스에는 없지만 우리에게 딱 맞는 것

레퍼런스의 **메모지**를 우리 화면의 두 곳에 그대로 쓴다. 원래부터 메모 성격인 자리다.

```
아직 확인 안 된 정보   → 노란 메모지 + 마스킹테이프
오늘 살펴본 곳         → 민트 메모지 + 마스킹테이프
```

==================================================
3. 색 — 파스텔 채움 + 진한 잉크 선
==================================================

v4의 쨍한 바이올렛·핫핑크를 걷어내고 부드러운 파스텔로 내린다.
**글자는 거의 전부 진한 잉크색**이라 대비는 오히려 좋아진다.

```css
:root{
  /* 종이와 잉크 */
  --paper:#FDFBF3;
  --ink:#2E2E2E;          /* 선과 본문. 순수 검정 대신 따뜻한 먹색 */
  --ink-soft:#5B5B5B;     /* 보조 글자 */

  /* 파스텔 채움 */
  --butter:#FFE9A8;
  --mint:#CFE9D4;
  --blush:#FBD9DE;
  --sky:#CFE2F3;
  --lilac:#E0D7F5;

  /* 형광펜 */
  --marker:#FFE066;

  /* 상태 — 채움은 파스텔, 글자는 잉크 */
  --calm-bg:var(--mint);
  --check-bg:var(--butter);
  --burden-bg:var(--blush);
  --plain-bg:#E8E8E4;
}
```

**규칙**

- 글자색은 원칙적으로 `--ink` 하나다. 상태별로 글자색을 바꾸지 않는다. 바뀌는 것은 배경과 아이콘.
- 파스텔은 **채움 전용**이다. 글자나 선에 쓰지 않는다.
- 상태 구분은 **배경색 + 손그림 아이콘 + 글자** 세 가지를 항상 함께 쓴다. v1부터의 규칙이다.

==================================================
4. 선과 모서리 — 삐뚤빼뚤하게
==================================================

이 스타일의 핵심은 **"완벽한 사각형이 하나도 없다"** 는 인상이다.

## 4-1. 손그림 모서리

CSS의 8값 `border-radius`로 손으로 그린 상자를 만든다. 이미지도 SVG도 필요 없다.

```css
:root{
  --hand-1:255px 15px 225px 15px / 15px 225px 15px 255px;
  --hand-2:15px 225px 15px 255px / 225px 15px 255px 15px;
  --hand-3:210px 20px 180px 30px / 20px 190px 25px 200px;
  --hand-pill:120px 90px 110px 100px / 90px 110px 95px 120px;  /* 알약 대용 */
  --hand-sm:14px 22px 16px 20px / 20px 15px 22px 16px;         /* 작은 요소 */
}
```

- 카드마다 `--hand-1 / 2 / 3`을 **번갈아** 준다. 전부 같은 모양이면 손그림으로 보이지 않는다.
- 버튼·칩은 `--hand-pill`. v4의 `border-radius:9999px`를 대체한다.

## 4-2. 잉크 선

```css
border:2.5px solid var(--ink);
```

- 굵기는 2.5px 기준. 작은 요소는 2px.
- **하드 섬도우(offset shadow)는 걷어낸다.** 깊이는 선과 기울기가 만든다.
- 꼭 필요하면 아주 옅게: `box-shadow:2px 3px 0 rgba(46,46,46,.10)`.

## 4-3. 기울기

```css
.tilt-a{transform:rotate(-.5deg)}
.tilt-b{transform:rotate(.6deg)}
.tilt-c{transform:rotate(-.35deg)}
```

- **메모지와 시설 카드에만** 준다. 대화 카드 전체나 입력창은 기울이지 않는다.
- 최대 1도. 그 이상은 고장 난 화면으로 보인다.
- 기울인 요소 안의 글자는 반듯해야 하므로, 부모만 회전시키고 자식은 건드리지 않는다.

## 4-4. 진짜 흔들리는 선이 필요하면

`feTurbulence` + `feDisplacementMap` SVG 필터로 실제로 선을 떨리게 할 수 있다.
다만 **글자가 든 요소에는 절대 걸지 마라.** 글자가 뭉개지고 스크린리더와 무관하게 읽기가 나빠진다.
장식용 SVG 도형에만 허용한다.

==================================================
5. 형광펜과 마스킹테이프
==================================================

## 5-1. 형광펜 강조

```css
.marker{
  background:linear-gradient(180deg,transparent 52%,var(--marker) 52% 94%,transparent 94%);
  padding:0 .18em;
  box-decoration-break:clone;
}
```

쓰는 곳: 브랜드 이름, 표제의 핵심 단어 하나, 판정 문구의 핵심 단어. **한 화면에 3개를 넘기지 않는다.**

## 5-2. 마스킹테이프 메모지

```css
.note{
  position:relative;background:var(--butter);border:2.5px solid var(--ink);
  border-radius:var(--hand-2);padding:20px 18px 16px
}
.note::before{
  content:"";position:absolute;top:-11px;left:50%;width:86px;height:22px;
  translate:-50% 0;rotate:-2.5deg;
  background:repeating-linear-gradient(45deg,rgba(255,255,255,.55) 0 6px,transparent 6px 12px),var(--blush);
  border:1.5px solid rgba(46,46,46,.35);opacity:.9
}
```

테이프 색은 메모지 색과 다르게 준다. 노란 메모에는 분홍 테이프, 민트 메모에는 파랑 테이프.

==================================================
6. 폰트 — 손글씨는 액센트만 (가장 중요)
==================================================

여기서 실수하면 서비스가 망가진다. 반드시 그대로 지켜라.

## 6-1. 왜 제한하는가

- 이 서비스의 주 사용자는 **부모님 세대**다. 한글 손글씨체는 획이 얇고 자간이 불규칙해 본문에서 읽기 어렵다.
- 화면에 담기는 것은 **주소, 시설명, 판단 결과** 같은 사실 정보다. 잘못 읽히면 서비스 목적이 무너진다.

## 6-2. 폰트 구성

```css
--font-body:"Pretendard Variable",Pretendard,system-ui,"Malgun Gothic",sans-serif;
--font-hand:"Gaegu","Nanum Pen Script","Pretendard Variable",system-ui,sans-serif;
```

Google Fonts에서 `Gaegu`(300/400/700)를 불러온다. 한글 손글씨체 중 획이 두껍고 읽기가 나은 편이다.
`Nanum Pen Script`는 더 얇으니 보조 폴백으로만 둔다.

## 6-3. 손글씨를 쓰는 곳

```
브랜드 이름 / 표제 h1 / 섹션 라벨(우리 가족 조건, 가까운 시설, 출처)
메모지 제목 / 첫인사 첫 줄 / 장소 마무리 문장 / 방문 요약
```

## 6-4. 손글씨 금지 구역 — 어기면 되돌려라

```
❌ 주소
❌ 시설명 (화장실, 수유실 …)
❌ 판정 문구 (방문 전 확인할 정보가 있어요 …)
❌ 조건 결과의 근거 문장
❌ 오류 문구
❌ 지도 링크·복사 버튼 라벨
❌ 입력창과 placeholder
❌ 출처의 기관명·기준일
❌ 모든 숫자
```

## 6-5. 크기 보정

손글씨체는 같은 px에서 작아 보인다. 손글씨를 쓰는 자리는 **본문 기준보다 3~4px 크게** 잡는다.

```
본문 Pretendard 17px  ↔  손글씨 Gaegu 21px
라벨 Pretendard 15px  ↔  손글씨 Gaegu 19px
```

## 6-6. 폴백

CDN을 못 받아오면 Pretendard로 떨어진다. 그 상태에서도 레이아웃이 깨지지 않아야 한다.
손글씨 자리에 `line-height`를 고정값(px)으로 박지 마라. 폰트가 바뀌면 어긋난다.

==================================================
7. 온이 — 손그림 얼굴을 준다
==================================================

"친근한 가족 느낌"을 가장 크게 좌우하는 요소다. 캐릭터를 하나 그린다.

## 7-1. 생김새

- 인라인 SVG. 외부 이미지 없음.
- 원 안에 잉크 선으로 그린 최소한의 얼굴. 눈 두 점 + 입선 하나.
- 크기 40px, 선 굵기 2.5px, 둥근 선끝.
- 원 배경은 `--butter`, 테두리는 `--ink`.

## 7-2. 표정 4종을 판정과 1:1로 잇는다

이건 장식이 아니라 **정보의 두 번째 통로**다.

| `comfort.level` | 표정 | 함께 나가는 글자 |
| --- | --- | --- |
| COMFORTABLE | 웃는 입 `◡` | 편안하게 이용할 가능성이 높아요 |
| CHECK_NEEDED | 한쪽만 올라간 입 + 눈썹 하나 | 방문 전 확인할 정보가 있어요 |
| BURDEN_POSSIBLE | 살짝 내려간 입 | 현재 조건에서는 부담이 있을 수 있어요 |
| INSUFFICIENT_DATA | 일자 입 + 물음표 | 판단할 정보가 부족해요 |

**표정만으로 뜻을 전하지 않는다.** 글자는 지금처럼 항상 함께 나간다. SVG에는 `aria-hidden="true"`.

## 7-3. 어디에 두는가

```
첫인사 말풍선 왼쪽에 한 번
답변 카드의 판정 줄 왼쪽에 한 번
그 밖에는 두지 않는다
```

말풍선마다 얼굴을 붙이면 다시 채팅앱이 된다. 두 자리로 끝낸다.

==================================================
8. 손그림 장식
==================================================

## 8-1. 종류

인라인 SVG로 8개만 만든다. 전부 `aria-hidden="true"`, `pointer-events:none`.

```
별(4갈래 반짝임) · 하트 · 곡선 점선 화살표 · 물결 밑줄
동그란 스마일 · 나선 · 점 세 개 · 작은 꽃
```

선 굵기 2~2.5px, 둥근 선끝, 색은 `--blush` `--sky` `--marker` `--mint`를 돌려 쓴다.

## 8-2. 두는 곳과 개수

```
표제부        3~4개
첫인사 주변    2개
장소 마무리 줄  1개 (물결)
그 외          0개
```

**답변 카드 안에는 하나도 두지 않는다.** v4에서 정한 원칙 그대로다.
좁은 화면(700px 미만)과 `prefers-contrast: more`에서는 전부 감춘다.

## 8-3. 밑줄과 체크

- 표제의 핵심 단어 아래 물결 밑줄 SVG.
- 조건 칩의 체크는 네모 상자 + 손으로 그린 체크. 지금의 `＋ / ✓` 문자를 SVG로 교체한다.

9. 컴포넌트별 적용
==================================================

| 요소 | v4 | v5 |
| --- | --- | --- |
| 카드 테두리 | 2px 직선 + 하드 섬도우 | 2.5px 잉크 + `--hand-*` 모서리, 섬도우 제거 |
| 버튼·칩 | 알약 + 하드 섬도우 | `--hand-pill` + 잉크 선, 눌리면 1px 내려감 |
| 봇 말풍선 | 흰 바탕 + 각진 한쪽 | 흰 바탕 + 손그림 모서리 + 왼쪽 아래 꼬리 |
| 내 말풍선 | 바이올렛 채움 | `--sky` 채움 + 잉크 글자 + 오른쪽 아래 꼬리 |
| 판정 띠 | 색 띠 | 온이 얼굴 + 파스텔 채움 + 형광펜 강조 |
| 시설 카드 | 사각 카드 | 살짝 기울인 손그림 카드 |
| 픽토그램 | 색 원 + 굵은 아이콘 | 잉크 선 아이콘 + 파스텔 원, 선 굵기 2.5px |
| 미확인 정보 | 노란 박스 | 노란 메모지 + 마스킹테이프 |
| 방문 요약 | 민트 알약 | 민트 메모지 + 마스킹테이프 |
| 입력창 | 직사각 + 포커스 섬도우 | 손그림 모서리, 포커스 시 잉크 선 굵어짐 |
| 로딩 | 점 세 개 튀기 | 손그림 점 세 개가 위아래로 통통 |
| 배경 | 점 그리드 | 무지 크림. 장식이 대신한다 |

말풍선 꼬리는 CSS `::after`로 그린다. 잉크 선이 이어져 보이도록 배경색과 테두리를 같이 맞춘다.

```
51. 손글씨 폰트가 금지 구역에 적용되지 않았다
```
